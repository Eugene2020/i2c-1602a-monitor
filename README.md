# I2C LCD монитор температуры и аптайма

Проект выводит текущий аптайм микроконтроллера с момента включения и внутреннюю температуру чипа. Данные на дисплее обновляются 1 раз в секунду. Аптайм считается через SysTick с момента включения. Температура читается с внутреннего датчика STM32 через ADC.

## Устройства и подключение

- STM32F103C8T6 (Blue Pill)
- LCD 1602A HD44780-совместимый
- I2C-адаптер PCF8574T V2
- Проргамматор ST-Link V2
- Потенциометр B20K
- Резисторы 4.7 кОм х2

STM32 | PCF8574T
```
5V  - VCC 
GND - GND
PB6 - SCL
PB7 - SDA
```
Резисторы 4.7 кОм на SDA и SCL к +5V (подтягивающие)

PCF8574T | LCD 1602A
```
VSS - GND  
VDD - VCC  
V0  - Средний вывод потенциометра В20К
RS  - P0   
RW  - P1   
E   - P2   
D4  - P4   
D5  - P5   
D6  - P6   
D7  - P7   
A   - VCC  
K   - GND  
```

## Сборка и прошивка

Нужное ПО:
- `arm-none-eabi-gcc`
- `make`
- `git`

Процесс сборки и прошивки:
- Склонировать проект
- В корне склонировать библиотеку libopencm3 
`git clone https://github.com/libopencm3/libopencm3.git`
- Собрать библиотеку `cd libopencm3 && make && cd ..`
- Собрать проект `make`
- Прошить `make flash`

## Ограничения

Без калибровки внутренний датчик температуры может показывать не совсем корректные значения
